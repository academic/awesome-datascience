# Contributing

Thanks for taking the time to contribute.

## What you can contribute

- Add new resources (links, tools, courses, books, etc.)
- Fix broken links
- Remove outdated resources
- Improve organization (move items to a more appropriate section)
- Fix typos and formatting issues

## How to add a new resource

- Add the resource to the most relevant section in `README.md`.
- Use the existing style for that section.
- Prefer authoritative sources (official docs, original GitHub repo, publisher site).

### Entry format

Use a consistent bullet format:

- `[Name](URL)` - Short description.

Guidelines:

- Keep descriptions short (ideally one sentence).
- Use title case for the link text when it matches surrounding entries.
- Avoid marketing language and superlatives.
- If there are similar items already listed, add yours near them.
- If the section is alphabetized, keep it alphabetized.

## Links

- Prefer `https://` when available.
- Avoid URL shorteners.
- If a site blocks automated link checking but is a valid resource, it may need to be ignored by the link checker configuration.

## Pull request checklist

- Your change is in the right section.
- The link works.
- The description is short and matches the repo style.
- Link checks pass (or you explained why they fail and proposed an ignore pattern).
- You completed the PR template, including payment model, commercial/promotional disclosure, license type, and your relationship to the project.

PRs that don't follow the template are closed automatically, with a comment listing what is missing. Fix the description, then reopen the PR or open a new one.

## Commercial and Promotional Links

- Every PR must fill in the "Commercial / Promotional Disclosure" section of the PR template. Tick "None" if the contribution is non-commercial; otherwise tick each option that applies (marketing, paid service, sponsor tier, other) and explain it under "Disclosure details".
- Open source projects are listed for free only if they do no marketing and have no paid offering. If a project, open source or not, does marketing or earns money through its listing (lead generation, self-promotion, a funnel to a product or business, a hosted/cloud version, a paid tier, an enterprise edition, paid support, etc.), the listing is promotion and requires payment of $1/month or $12/year via [GitHub Sponsors](https://github.com/sponsors/hmert).
- If you tick anything other than "None" in the disclosure, you must choose a paid option under "Payment Requirement" and add your payment reference (GitHub Sponsors username or transaction ID). Otherwise the PR is closed automatically.
- The PR is labeled automatically based on what you tick.
- Listings found to do marketing or earn money without disclosure and payment are closed, or removed from the list if already merged.
